## 2. 终态能力面

- **模型面**：`superagentteam_post_message` / `cross_post_message` /
  `multi_mention` / `thread_context` 四工具；v1 worker extension 只注册这四个
  canonical 名称。
- **执行面**：Thread → InvocationRecord parent → TurnExecution child →
  InvocationAttempt append-only；T1–T4 owner 分离；durable stream + recovery。
- **入口面**：默认 `startDaemon` 走 A2A control plane；operator 用
  `thread post` / `multi_mention` / `thread` CLI；CLI `thread` 默认 `f018.db`。
- **安全面**：child-TurnExecution credential token；control server 五层校验
  （token → credential → worker binding → running turn → allowedTools）；
  token 不落 TurnExecution/InvocationRecord/UI 读取面；worker 不跨 token 复用。
- **恢复面**：startup cutoff/恢复、T4 response_pending、expired claim、
  multi_mention pending callback、单后台收敛器。

## 4. 部署前置（R5 cutover 后）

- `dataDir` 必须有 `agent-catalog.json` + `accounts.json`；缺失时默认 A2A
  daemon 以 `control_plane_failed` 失败收口，这是 cutover 预期行为。
- 默认创建 `f018.db`；`control.db` 只在显式 `controlPlane: {}` legacy 路径创建。
- CLI 需要 operator credential（`superagentteam auth init`）。
- worker 需要可解析的 pi CLI（`PI_CLI` 或构建产物）与 v1 `a2a-extension`。
- token 由 daemon spawn 注入 worker env；不需要 operator 手工配置。

## 5. Legacy 冻结边界

- `task/backlog/review/merge/sop/schedule/deployment/budget/...` 仍是 frozen
  task-first code delivery 路径，读写 `control.db`；**不进入 A2A runtime**。
- `thread --engine legacy` 只作为历史线程逃生口；新 CLI/daemon 默认不依赖。
- `messages.kind` / legacy 列的删除未在本轮执行；需要 operator 明确授权 +
  回滚快照后再做。
