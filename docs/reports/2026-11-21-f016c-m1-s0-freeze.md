# F016c-M1 S0 freeze

> 本文冻结 M1 的 DTO、session bridge、owner gate、idempotency、error/cursor
> 规则与 contract test 矩阵。它是 0029 §4 S0 的交付物；代码切片在本文 review
> 通过后开始。本文不写产品代码。

## 0. 范围与代码事实

- M1 只做 HTTP API；M2 live events、P3 cancel 不在本轮。
- daemon HTTP server 在 `daemon.ts` 的 `createServer`，目前只有 `/health`、
  `/ready`、`/metrics`；M1 在同一 server 上增加 `/api` 与 `/auth/console`。
- `A2ADaemonControlPlane` 公开 `runtime: A2ARuntime`；`A2ARuntime` 已暴露
  `threads/messages/queue/records/turns/attempts/ingress/registry` 等。
- operator credential 在 `auth/operator.ts`：Ed25519 keypair、签名/验签、
  fingerprint；目前只有 CLI 使用，浏览器 session bridge 尚未实现。
- `OperatorMessageIngress.submit` 已支持 messageId replay；replay 比较
  thread/user/body/target set，body 或 targets 不同会抛
  `ingress_message_id_conflict`。
- `LiveInvocationView` / `QueueView` / `MessageDispatchSummary` 在
  `0007 §3.10`（DP-F018SURFACE-3=A）定义为 F018 domain DTO，但 F018 收口时
  **未落地代码**；M1 S0 接走 `QueueView` / `LiveInvocationView` 的 M1 子集，
  `MessageDispatchSummary` 继续 deferred。归属校正：因 F018 收口时未落地，
  改由 F016c S0 交付；F018 报告 §6 未记这一项，本文补录。
- **cats 不是 SuperAgentTeam 领域概念**，只是 classic Hub 的 transport 名。
  内部/授权一律 `AgentConfig` / `agentId`；M1 提供 canonical `/api/agents`，
  `/api/cats` 仅作 Hub 兼容 alias（`catId = agentId`，只用于显示/provenance，
  不作授权）。

## 1. DTO freeze（M1 子集）

以下类型来自 `@superagentteam/shared/types` 或在其基础上做 Hub 投影；本文件
只冻结 M1 字段，不新增持久化列。

### 1.1 ThreadView

来源：`ThreadStore` + participants。

```ts
interface ThreadView {
  id: string;
  projectPath: string;
  title: string | null;
  titleSource?: "user" | "agent" | "system";
  createdBy: string;
  participants: string[];       // agentId；显示名走 /api/agents（Hub alias /api/cats）
  lastActiveAt: number;
  createdAt: number;
  updatedAt: number;
  deletedAt?: number | null;
}
```

`participants` 是路由/上下文快照，不是 ACL；所有 thread 级读写的授权仍走
`createdBy` owner gate。

### 1.2 MessageView

来源：`StoredMessage`，按 Hub 可消费形状投影；`seq` 不暴露（内部排序用）。

```ts
interface MessageView {
  id: string;
  threadId: string;
  type: "user" | "assistant" | "system" | "connector";
  from: MessageFrom;            // user/agent/system
  catId?: string;               // Hub alias = agentId；仅显示/provenance，不作授权
  content: string;
  contentBlocks?: MessageContent[];
  toolEvents?: StoredToolEvent[];
  lifecycle?: MessageLifecycle;
  replyTo?: string;
  mentionsUser?: boolean;
  timestamp: number;
  updatedAt: number;
  thinking?: string;
  extra?: StoredMessage["extra"];
}
```

`extra.rich` 必须是 `{v:1, blocks:[...]}`；写面校验失败返回 422，不把坏 JSON
塞给 Hub。`lifecycle` 按 `StoredMessage` 原样投影，不在 M1 新增字段。

### 1.3 QueueView

来源：`QueueLedgerStore.listQueued` / `listActive`；cap 按 kind 分开，当前
`QUEUE_CAP_PER_KIND = 5`。

```ts
interface QueueView {
  threadId: string;
  cap: { perKind: 5 };
  entries: Array<{
    queueEntryId: string;
    sourceRecordId: string;
    status: "queued" | "claimed";
    priority: "urgent" | "normal";
    position: number;
    targetAgentIds: string[];
    claimedBy: string | null;
    enqueuedAt: number;
    updatedAt: number;
  }>;
}
```

排序：priority 先、同 priority FIFO、按 position；不返回已删除 entry。

### 1.4 LiveInvocationView

来源：tracker active slots + durable `InvocationAttempt`/`TurnExecution`/response
message；实现 `getThreadLiveInvocations`。

```ts
interface LiveInvocationView {
  agentId: string;
  turnExecutionId: string;
  parentInvocationId: string;
  startedAt: number;
  childStatus: "running" | "completed" | "failed" | "interrupted" | "canceled";
  responseStatus: "processing" | "completed" | "failed" | "interrupted" | "canceled" | "missing";
  evidenceRank: "record+tracker" | "tracker-only" | "record-only";
}
```

规则：按 `turnExecutionId` 去重；过滤 response 已 terminal 的成员；thread/user
scoped；按 `startedAt` 升序；不返回 terminal 的幽灵执行。

### 1.5 MessageDispatchSummary（deferred）

`0007 §3.10` 定义了该 DTO，但 M1 不提供路由。M1 用 queue + live 回答“在跑/
排队/跑完没”；`MessageDispatchSummary` 路由留 M2/后续。S0 只保留类型位，
不把它写进 M1 endpoint 表。

### 1.6 AgentView / HubCatView / ConfigView

```ts
interface AgentView {
  id: string;
  displayName: string;
  avatar?: string;
  color?: { primary: string; secondary: string };
  enabled: boolean;
  status?: "idle" | "thinking" | "working" | "error" | "offline";
}
// /api/cats alias returns the same objects with catId = id.
interface HubCatView extends AgentView { catId: string }
interface ConfigView { config: { ui: { bubbleDefaults?: Record<string, unknown> } }; }
```

数据源：agent catalog + safe defaults；canonical 是 agent，`cats` 只是 Hub
transport alias；只作显示，不作授权，不返回 account/secret。

## 2. Session bridge

### 2.1 Console-link

1. CLI `superagentteam auth console-link`（loopback only）读取 daemon state 的
   `healthPort`（或 `--url`），用 operator 私钥签一个短时效 payload：
   `{ sub: "operator:<fingerprint>", aud: "daemon", iat, exp, nonce }`。
2. 打印一次性 URL `http://127.0.0.1:<port>/auth/console?token=...`；token 不写
   日志/错误 body。
3. `GET /auth/console?token=` 验签、消费 nonce（daemon 内存 TTL map）、创建
   server-side session，Set-Cookie `superagentteam_session`
   （HttpOnly/SameSite=Strict；https 时 Secure），然后 302 到 `/` 或返回 JSON。

### 2.2 Session / CSRF

- `GET /api/session`：有 session 返回 `{userId, csrfToken}`；无/失效 401。
- 写请求必须带 `x-csrf-token`；双重提交校验。
- Origin allowlist：只允许配置的 Hub origin（默认
  `http://localhost:3000`；显式 `SUPERAGENTTEAM_HUB_ORIGIN`）；拒绝其他 Origin。
- 显式拒绝身份 header：`authorization`、`x-invocation-id`、
  `x-callback-token`、`x-agent-key-secret`、`x-cat-cafe-user`。
- 无 cookie/无效 session 一律 401，不落 `default-user`。
- TTL：console token 5 分钟；browser session 15 分钟 idle + 8 小时 absolute，
  认证请求滑动续期；S0 review 可调整。

## 3. Owner gate / idempotency / errors

### 3.1 Owner gate

- 所有 thread 级端点（`/threads/:id`、`/messages`、`/queue`、`/live`）统一：
  `session.userId === thread.createdBy`，否则 403 `forbidden`。
- 列表按 `createdBy` 过滤；不允许通过 query 参数越权。
- `/api/agents`、`/api/cats`、`/api/config` 不是 thread 级，但仍要求 session（读）；
  `catId` 永远不能替代 `agentId` 做授权或路由。

### 3.2 Idempotency

- `POST /api/messages`：要求 `idempotencyKey`；API 派生稳定
  `messageId = msg:<sha256(threadId\0userId\0key).slice(0,32)>`，传给
  `OperatorMessageIngress.submit`。同 key + 同 body/targets replay；不同
  body/targets → 409 `idempotency_conflict`（ingress 的
  `ingress_message_id_conflict`）。
- `POST /api/threads`：要求 `idempotencyKey`；派生
  `thread:<sha256(userId\0key).slice(0,32)>`。同 key + 同 projectPath/title
  replay；不同 payload → 409。
- 重放不产生双消息/双 queue/双 thread。

### 3.3 Error / cursor mapping

沿用 0029 §3.1，并冻结 cursor/body 粒度：

- 损坏/未知的 cursor 类参数（`before`、未知过滤值）→ 200 空页 +
  `query_warnings: string[]`（可观测标记/日志），不 400。
- 类型/结构非法的 body 或必填参数缺失 → 400 `invalid_input`。
- 无/无效 session → 401 `unauthorized`；CSRF → 403 `csrf_failed`；
  非 owner → 403 `forbidden`。
- `thread_not_found` → 404；`use_multi_mention` / `agent_disabled` /
  `target_invalid` → 422；`queue_full` → 429；`idempotency_conflict` → 409；
  legacy 写 → 501；daemon/依赖不可用 → 503。

## 4. Legacy 面

- 读端点（backlog/workflow SOP/approval/tasks/artifacts/labels/workspace）：
  `200` + 空列表 + `disabled:true`；UI 隐藏，不展示空面板。
- 写端点（approval decide/task write/queue control/edit/delete/recall）：
  `501`（按语义可用 404），不返回伪成功。
- 不读 `control.db` 作为任何 A2A 面数据源；legacy 只读若要做，另有授权。

## 5. Contract test 矩阵

| 面 | 必测 |
|---|---|
| session | console token 有效/过期/replay；无 cookie 401；CSRF 负例；Origin 负例；身份 header 拒绝 |
| thread | list/detail/create；owner 负例；404；重复 create 幂等/冲突 |
| messages | cursor 正常/损坏；`query_warnings`；append 幂等 replay/冲突；targets 0/1/>1；queue_full 429 |
| queue/live | 空读 200；terminal 过滤；tracker/durable 去重；startedAt 排序；owner 负例 |
| agents/cats/config | 显示字段；不返回 account/secret；不作授权；`/api/cats` alias = `/api/agents`，`catId = agentId`，不能用 catId 绕过授权 |
| legacy | 读 200 空 + `disabled:true`；写 501；不触碰 control.db |
| data boundary | 全程只开 `f018.db`；不出现 `control.db` 读写 |

## 7. 开放问题（S0 review）

1. Session TTL/滑动续期取值（15min idle / 8h absolute 是建议值）。
2. `LiveInvocationView.responseStatus` 的 terminal 子状态是否直接复用 R
   lifecycle；evidenceRank 的映射细节。
3. message cursor 形状：`before=<timestamp>:<id>` 与 Hub 的兼容；`query_warnings`
   的 code 集合。
4. Thread create 的派生 ID 是否可接受（`thread:<hash>`），还是允许 client
   提供 `id`。
5. Hub origin 配置方式：环境变量 vs daemon options；默认 `localhost:3000`。
