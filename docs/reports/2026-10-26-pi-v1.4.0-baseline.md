# pi v1.4.0 baseline verification

## Host

- OS: WSL2 (`6.6.87.2-microsoft-standard-WSL2`)
- Node: `v24.19.0` (also checked `v22.22.2` for the auth race)
- npm: `11.17.0`
- Date: 2026-10-26

## Commands

```bash
NODE_ENV=development npm install --ignore-scripts

# The model catalog is a generated, gitignored artifact. Use the revision pinned in nix/model-catalog.json.
curl -fsSL -o /tmp/pi-catalog.json \
  'https://pi.dev/api/models/revisions/sha256-7fe1b41feaf43a7aad4bc832e6b306c7ced56e6d41bbc724b74e91eeacff6edf?types=chat,image,classifier'
node packages/ai/scripts/hydrate-model-catalog.ts /tmp/pi-catalog.json

NODE_ENV=development npm run build:offline
NODE_ENV=development ./test.sh
```

`NODE_ENV=development` is required on this host: the shell default is `NODE_ENV=production`, which makes npm skip devDependencies (for example `@types/cross-spawn`) and breaks `build:offline`.

## Known failures / deviations

1. **`packages/env` — 6 suites cannot start.** The tests require the Rust daemon binary at `packages/env/daemon/target/debug/pi-env`. This host has no `cargo`/`rustc`. Prerequisite: install Rust and run `npm run build:daemon` in `packages/env`.
2. **`packages/coding-agent` clipboard tests — 12 failures on WSL2.** `isWSL()` reads `/proc/version`; the tests assume native non-WSL Linux and therefore do not expect `wl-paste`/`wslpath` fallback calls. Not a codeteam regression; run these on a non-WSL Linux CI runner for a clean signal.
3. **`packages/coding-agent` auth-storage coalesced reload — 1 failure.** Reproduced on Node `22.22.2` and `24.19.0`. The test writes same-length credentials (`old` → `new`) in the same revision tick; the mtime/size revision can remain unchanged, so the read returns the cached old value. Treat as an upstream test/revision-granularity flake until confirmed otherwise.
4. **`packages/coding-agent` model-runtime-classifiers — 1 failure.** The pinned catalog's `typesafe/jev-latest` entry declares `input: ["text"]`, while the test classifies an image. This is a pinned-catalog/fixture mismatch, not a codeteam change.

After installing `fd 10.5.0` into the host PATH, the fd-dependent `find` tests pass; the remaining coding-agent failures are the 14 listed above (1 auth-storage + 12 clipboard + 1 model-runtime).

## W0a implication

The build baseline is usable on `v1.4.0`. The full upstream test suite is not green on this WSL2 host. W0a must either run the affected suites on a supported Linux CI runner, or record these deviations and run the codeteam-specific L0/session/Hub spikes separately. Do not report the full suite as green from this host.
