## 2. 真实 CLI dogfood

测试 `test/cli-dogfood.test.ts` 用真实 `dist/cli.js` 跑完整路径：

```text
backlog create (feature:F007)
→ backlog approve
→ backlog dispatch --to profile:eval
→ thread list/show
→ thread post --to profile:eval
→ task create
→ thread post 行首 @profile:eval（typed inbox）
→ queue claim + cutoverQueueEntry 写入真实 agent_response
→ thread tail --after-seq 0 读出 agent 回复
→ approval request/list/show/approve
→ merge execute（临时 git repo，service:merge-owner receipt）
→ backlog done
→ thread post --kind verdict
→ sop evidence visionGuardDone message:<id>
→ sop update --stage completion
→ sop show + gate telemetry
```

结果：1 个测试通过；operator 不需要 Web。agent 回复由 W1 durable `messages` /
`queue_entries` / `cutoverQueueEntry` 写入，真实模型 runner 仍是 W5。

## 5. 显式边界与未覆盖项

1. **CLI-first，不是 HTTP/MCP-first**：W4 的 operator surface 是 CLI；W7a 复用
   service 暴露 HTTP/事件，不重写语义。`sop-bulletin.md` 已加 2026-10-28 边界注。
2. **agent runner 归 W5**：dogfood 的 agent 回复由真实 cutover 写入，不是模型调用；
   W5 QueueProcessor/AgentRouter/pi kernel 接上后替换测试 executor。
3. **approval materialization 归 W7/W8**：W4 的 approve 只写 `approvals`；
   merge hard gate 的 materialize/executor 在 local MergeExecutor 内完成，外部
   adapter 仍在 W8。
4. **false block / false pass 标注**：W4 telemetry 提供通过率/block 原因/剪枝候选；
   误判标注与 eval 决策归 W6，不在 W4 造 eval 平台。
5. **live review corpus n≥20**：仍按 F006 ledger 挂 W4/W6；W4 没有真实模型调用。
6. **merge record**：local 路径已可用（operator key 或 daemon credential）；GitHub
   adapter 的 squash/reconciliation 归 W8；本地 `merge execute` 使用 `--no-ff`。
7. **多 task / worktree pool / 并发 dispatch**：W5。

## 6. 风险与回滚

| 风险 | 处置 |
|---|---|
| SOP 又变成控制器 | stage 不校验迁移；只有 completion/evidence 写 gate；code review 固定 |
| verified 伪造 | 写权拆分 + evidence_ref 解析 + SQL CHECK + 422 测试 |
| merge 绕过 gate | MergeExecutor 先跑 gate；receipt 必须 service principal + gate evidence |
| legacy merge 被当完成证据 | completion / fresh projection 只认 `service:merge-owner` + gate evidence |
| CLI 成为第二状态机 | CLI 只调 store/service；不复制状态判断 |
| agent runner 被误读为 W4 已接 | dogfood 明确使用 cutover；W5 接 runner |

回滚：migration 009/010 additive；CLI/service/gates 新增文件；回滚到
`1669f50f4` 即可，不迁移外部数据，不清 audit。
