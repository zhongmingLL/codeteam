## 2. 能力面

- **R4-a**：`ThreadContextService`（current/explicit thread、同 user、未删除、
  anchor 窗口、opaque cursor、visibility 复用 `HistoryAssembler.visibleTo`）。
- **R4-b**：`LoopGuardService` 从 durable causal 链重建 A2A lineage；同一 unordered
  pair 连续 short/no-substantive ≥2 warn、≥4 block；实质 tool 或 >200 chars 输出重置；
  restart 后无内存状态仍可重建。
- **R4-c**：multi_mention 逐 target cancel/retry；全 target canceled → request
  `failed`（不再 done+allFailed 双语义）；partial cancel 保留 received sibling；
  callbackFailed 与 marker 同事务；backfill `responseState` 按 R 实际 lifecycle；
  T3 与 cancel 路径共用 `finalStatus`。
- **R4-d1**：`canceled:<reason>` 前缀覆盖 cancel API、T3 canceled-child 投影、
  backfill canceled 分支；`finalStatus` 不再文案嗅探。startup `recover()` 扫非终态
  group：parent canceled → `canceled:operator_abandon`，parent 缺失 →
  `canceled:parent_missing`，关闭 abandon 提交后的 crash 窗口。
- **R4-d2**：
  - `domains/a2a/observation.ts`：v1-native pure classifier，识别四个 model-facing
    工具（`superagentteam_post_message` / `superagentteam_cross_post_message` /
    `superagentteam_multi_mention` / `superagentteam_thread_context`）及其 credential
    裸名；拒绝 retired send/handoff 家族。agent final response 的 text-`@` 明确不解析、
    不产生 `missing_a2a_tool_call`（0007 §3.0）。
  - LoopGuard 依赖改为必填（`A2AToolService` / `MultiMentionOrchestrator`），
    `buildA2ARuntime` 暴露 `loopGuard`；warn 以 typed `warnPingPong` 返回并补充
    post/cross 传播，杜绝 queue 注记或第二条 system message。
  - E20 restart E2E：expired claim restore、pending multi_mention callback 跨重启恰好
    一次、response_pending 从 durable draft 结算、重复 startup/reaper 不重复 terminal、
    当前进程 running child 受 cutoff 保护。
