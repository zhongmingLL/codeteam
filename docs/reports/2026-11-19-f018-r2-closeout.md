## R2 能力面（same-thread A2A 全链）

- **ingress**：operator 显式 `@`/隐式 5 步链解析，message+queue 单事务
  admission，deleted-thread/targets 门禁，幂等 replay。
- **dispatch**：QueueProcessor 候选选择/preflight 三分类/Phase A 单事务/
  Phase B per-target 事务（失败隔离），retireTargets anchor 语义，
  RetryDeferrals 指数退避。
- **execution**：WorkerPool（ephemeral、poolKey 复用、warmTtl-0、metrics）
  + PiWorkerSpawnPort（真实 pi RPC 参数契约）+ RunAgentTurn（loadHistory →
  prompt onAccepted ack 门 → stream → T1/T2，provider 失败按 delivery 分流）。
- **stream**：ResponseEventSink 全量 snapshot（100ms/4KB 节流）+
  AgentStreamEvent（seq/toolId）+ 首可见输出 0→1。
- **settlement**：T1-T4 四层 owner（child terminal / R commit / parent
  aggregate / recovery），delivery cursor promptDelivered 门控 ack，
  messageCount completed-only。
- **recovery**：TurnExecutionStartupReconciler（processStartedAt+1 收敛 +
  T4 + 重聚合）、InvocationOwnerReaper（liveness 证据判定 + 收敛链）。
- **retry/lifecycle**：requestRetry（同 entry 重派 attempt+1，canceled 不可
  复活）、abandon（唯一合法 terminal→terminal）、exact-entry requeue。
- **组装根**：`buildA2ARuntime` 一处接线（daemon/E2E 共用）。

## R2-d 证据

- requestRetry：a1 成功 + a2 delivered-failure → partial_failed → retry 只
  重派 a2（同 entry、attempt+1、旧行不可变）→ completed。
- abandon：failed → canceled + anchor 删除；completed/running 拒绝。
- startup：pre-process running child 收敛 interrupted/process_restart，
  attempt interrupted、T4 settle、parent 重聚合 failed；幂等。
- reaper：无 live worker 证据的 running child 收敛 interrupted/owner_reaped；
  二次 sweep 无操作；in-flight guard。
- 组装根 E2E（mock provider）：submit → drain → R committed → cursor/participant/
  parent completed → pool metrics 可消费。
