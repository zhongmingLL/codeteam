# DP-PLUGIN: plugin 拍板包

> **Operator 决定（2026-10-25）**：`DP-PLUGIN-1=A`、`DP-PLUGIN-2=A`。本 packet 已冻结；plugin 卡按 skill surface only + repo-local curated 收口。
>
> 来源：`../reuse-review/plugin.md`（approved）；三猫 review request `e3168435-73d6-4a82-a840-979596c21466`。结论：烁烁 accept、砚砚 accept、墨墨 accept-with-modify；无 P1，3×P2 + 11×P3 已回写。

## 0. 一句话

v1 的 plugin 只做 **skill surface**：repo-local curated `SKILL.md` + 瘦身 `manifest.yaml`，role allowlist 经 pi loader 注入；不做插件包/市场/运行时/Broker/grants。推荐 **A/A**。

## 1. 先看结论

| 决策 | 选项 | 推荐 | 影响面 | 不拍的后果 |
|---|---|---|---|---|
| DP-PLUGIN-1 v1 scope | A=skill surface only；B=full plugin framework | **A** | W0/W4 范围、攻击面、dogfood 速度 | B 会把外部包/运行时/市场拖进 W0/W4，直接撞零 secret 与已签 P0 源卡 |
| DP-PLUGIN-2 skill source/mount | A=repo-local curated + role allowlist + project root；B=plugin.yaml package + 多项目 symlink cascade | **A** | skill 供应链、跨项目隔离、mount 债 | B 会带回 manifest 权限面与 F228/F239/F301 的 mount/drift 债 |

## 2. DP-PLUGIN-1：v1 scope

| 选项 | 行为 | 价值 | 代价 |
|---|---|---|---|
| **A（推荐）** | 只取 skill surface：`SKILL.md` + 瘦身 `manifest.yaml` + role allowlist + pi `resourceLoader`；无 package/marketplace/inventory/Broker/runtime/grants | 攻击面缩到 operator 自己仓库里、自己审过的 markdown；W0/W4 可交付；与已签 P0 源卡一致 | 暂时没有插件市场/外部包/运行时 |
| B | full plugin framework：F202 的 manifest/admission/inventory/config/auth/intent/live + Broker + runtime + marketplace | 一次覆盖完整插件能力 | 范围/攻击面/状态面暴涨；与已签 P0 源卡冲突；W0/W4 dogfood 被拖慢 |

**推荐 A**：三猫一致；墨墨明确指出 B 与 operator 2026-10-24 已签的 `reuse/plugin.md` P0 scope 正面冲突。v1 的“plugin”就是 skill surface，不是市场。

## 3. DP-PLUGIN-2：skill source / mount

| 选项 | 行为 | 价值 | 代价 |
|---|---|---|---|
| **A（推荐）** | repo-local curated `SKILL.md` + 瘦身 `manifest.yaml`；frontmatter 是 name/description/triggers 唯一权威；role allowlist；project-level root；无 HOME/global symlink | 最小可审计加载路径；跨项目隔离；rollback 只动 manifest/profile | 多项目 skill 共享要等 P1 |
| B | `plugin.yaml` package + 多项目 symlink cascade / HOME mount | 接近 clowder 历史能力 | 带回 plugin manifest 权限面、mount 冲突/drift、跨项目泄漏；v1 无多项目需求 |

**推荐 A + 护栏**：

- frontmatter 是 name/description/triggers 唯一权威；manifest 只留 category/not_for/output/next/sop_step；重复字段 → invalid。
- 两级：index（id/name/description/triggers/next）常驻；body（SKILL.md 正文）按需；不把全文常驻 L1。
- `nextSkill` 经 agent repo read 落地；allowlist 只管 session 启动注入；mid-session loader 注入非 v1 承诺。
- path containment 用 `realpath(catalog_root)`；skill 目录不在 agent 可读面；多文件 skill fork 时合并为单文件。
- 第一防线 = curated + repo PR review；secret scan 是最后防线，不是准入条件。
- `tips_exempt` v1 drop；`SkillCatalogEntry.sourceKind` 只允许 builtin/curated。

## 4. 已定的安全/体验边界（随签字冻结）

- 不做自动 discovery、HOME/global mount、多项目 symlink cascade；`CODETEAM_SKILL_ALLOW_HOME_MOUNT=0`。
- 不执行 skill 目录里的 scripts；skill 内容不能改变 tool policy/permission/custody/approval。
- allowlist 空=不加载；悬空 skillId → session warning；`nextSkill` 被拒绝 → `next_skill_skipped_by_policy` 可见。
- skill load 不写 audit 洪水；只在 security-relevant failure 写 audit。

## 5. 不拍的后果

- DP-PLUGIN-1 不拍：W0/W4 的 skill surface 契约无法冻结，可能把 marketplace/Broker/runtime 误带入。
- DP-PLUGIN-2 不拍：skill 来源/mount 悬空，fork 可能继承 clowder 的 manifest 双源与 symlink 债。
- 两项都不影响 Wave A 已签契约，但 W0 skill 加载与 W4 SOP skill 建议不能开工。
