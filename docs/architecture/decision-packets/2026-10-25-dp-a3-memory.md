# DP-A3: memory 拍板包

> **Operator 决定（2026-10-25）**：`DP-MEM-1=A`、`DP-MEM-2=A`、`DP-MEM-3=A`。本 packet 已冻结；memory 卡按 A/A/A 收口。

## 0. 一句话

memory v1 做“项目文件证据索引”，不做个人/主动记忆；独立 `memory.db` + index worker；只读 index/rebuild。Operator 已拍：**A / A / A**。

## 1. 先看结论

| 决策 | 选项 | 推荐 | 影响面 | 不拍的后果 |
|---|---|---|---|---|
| DP-MEM-1 v1 范围 | A=file-evidence subset（threads defer）；B=全量 memory | **A** | W6 实现、隐私面、维护成本 | 范围回流，codeteam 可能变成第二套家庭记忆 |
| DP-MEM-2 存储 | A=独立 `memory.db` + worker；B=与 control DB 同库 | **A** | 索引扫描与 custody/approval 锁/事件循环竞争 | 大扫描可能阻塞 W1 控制面 |
| DP-MEM-3 写路径 | A=只 index/rebuild；B=reflection/proactive 写入 | **A** | 权限/隐私/生命周期 | W6 范围膨胀到 F271/F282/F287 |

## 2. DP-MEM-1：v1 memory 范围

| 选项 | 行为 | 价值 | 代价 |
|---|---|---|---|
| **A（推荐）** | 只索引 repo/docs/artifact 文件；thread messages/run_events defer→W6+；个人/主动/私密/品味/事件/画像记忆全 drop | 与代码交付目标一致；隐私面最小；W6 可交付；无假承诺 | 没有“猫的长期人格记忆”，暂时不能搜历史 thread |
| B | 全量 memory：person/proactive/cue/diary/taste/event | 复用面最大 | 需要 F276/F282/F287/F255 的隐私/lifecycle，W6 放不下 |

**推荐理由**：codeteam 是代码交付团队；W0-W4 dogfood 需要的是“找回项目文件证据”，不是“记住 operator 的私事”。个人记忆 lane 已有 F276/F282，不在 codeteam 重造。三猫 review 的 P1-1 已确认：thread messages/run_events 没有 source connector，v1 不把它们写进承诺；W6+ 再加 connector + cursor。

## 3. DP-MEM-2：memory DB 位置

| 选项 | 行为 | 价值 | 代价 |
|---|---|---|---|
| **A（推荐）** | 独立 `CODETEAM_MEMORY_DB`（默认 `CODETEAM_DATA_DIR/memory.db`）+ index worker 子进程；禁 ATTACH；不进备份 | FTS/scan 不抢 control DB 写锁/事件循环；可单独删除/重建 | 多一个 DB 文件；worker 进程管理 |
| B | 与 control SQLite 同库 | 少一个文件；事务简单 | FTS/扫描大事务与 handoff/approval 抢锁；回滚影响控制面 |

**推荐理由**：memory 是可重建索引，control plane 是不可重建责任真相；两者故障/备份/回滚节奏不同，物理隔离更安全。烁烁/砚砚/墨墨都确认：SQLite 锁是文件级；墨墨 P2-2 进一步要求 index 跑 worker 子进程，避免 CPU/IO 拖慢 custody/approval 的 HTTP 响应。

## 4. DP-MEM-3：写路径

| 选项 | 行为 | 价值 | 代价 |
|---|---|---|---|
| **A（推荐）** | 只做 index/rebuild，operator/daemon 触发；agent 只读；lesson/decision 走仓库文件被索引 | 权限/隐私面最小；索引可重建 | 没有 reflection/proactive 的“主动记忆” |
| B | 加 reflection/proactive 写入 | 更接近 clowder memory | 需要 F271/F282/F287 的 privacy/lifecycle，W6 放不下 |

**推荐理由**：写路径是隐私和权限的主要风险面；v1 只做只读索引，等 W6+ 有真实消费需求再开。

## 5. 不需要拍、已定的边界

- 不索引 home/credentials/secret/跨项目私有数据；roots allowlist + redaction。
- 内容级 secret redaction：path + payload 双层；命中 skip/redact + audit；memory_read 出口再脱敏。
- 空结果只代表索引范围，不说“不存在”；结果带 coverage/degraded/stale。
- lexical-first；semantic 可选，缺 provider 时 `degraded=lexical_only`。
- 不建第二 evidence store；`memory.db` 是唯一 evidence index。
- 独立 memory schema 在 `../memory-schema.md`；不进 0001 §12.2 control schema。
