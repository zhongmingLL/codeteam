# codeteam lessons

Durable lessons from delivered work. Each lesson records the observed symptom, the root cause, and a
guardrail that changes future behavior. A lesson without a guardrail is just a story.

## Format

```markdown
## LL-XXX: <short title>

- **Observed**: what happened, with source coordinates.
- **Root cause**: the mechanism, not the symptom.
- **Guardrail**: the concrete check or rule that prevents recurrence.
- **Scope**: feature / area.
```
